# Crew Radio

Crew Radio is a modern and responsive online radio website built with HTML, CSS, and JavaScript. It provides users with a simple and enjoyable way to listen to live radio, explore featured shows, and discover the latest music in a clean and intuitive interface.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and user-friendly interface
- Live radio streaming section
- Featured radio shows and programs
- Smooth navigation experience
- Fast loading and optimized performance

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/your-username/Crew-Radio.git
```

2. Navigate to the project folder.

```bash
cd Crew-Radio
```

3. Open `index.html` in your browser.
